<h1>Project: Calculator</h1>
A simple calculator app with several features.
<br>
This project is based on <a href="https://www.theodinproject.com/">The Odin Project</a>.

<h3>Features</h3>

- Basic calculations (add, subtract, multiply, and divide)

- Decimal support

- Easter egg when it is divided by zero

- Responsive Design implemented

<h3>Tech Stack</h3>

- Frontend: HTML CSS JavaScript
